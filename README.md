# Rizz · ریز — Android

**[⬇️ Download Rizz for Android (rizz.apk)](https://github.com/us-crypto/rizz-updates/raw/main/rizz.apk)**

1. Tap the link above and download `rizz.apk`.
2. Open the file. If Android asks, allow "Install unknown apps" for your browser.
3. Tap **Install**, then open Rizz.

New versions appear inside the app: **Me → Check for updates**.

---

۱. روی لینک بالا بزن و فایل `rizz.apk` را دانلود کن.
۲. فایل را باز کن. اگر اندروید پرسید، «نصب برنامه‌های ناشناس» را برای مرورگرت روشن کن.
۳. **نصب** را بزن و ریز را باز کن.

نسخه‌های جدید داخل خود اپ می‌آیند: **من ← بررسی به‌روزرسانی**.

iPhone: open the Rizz server address in Safari → Share → Add to Home Screen.

`latest.json` in this repo is read by the Rizz server to offer in-app updates. Files here are published automatically by the build.
